# My Finances

A local, single-user personal finance manager: transactions across named accounts, category budgets, and net worth (assets − liabilities + investments). Manual entry only, runs on-demand on your own machine, no auth, no cloud.

See [docs/PRD.md](docs/PRD.md) for the full spec — data model, functional requirements, and tech stack.

## Status

Pre-implementation. Planned stack: Java/Spring Boot/Gradle backend, React/TypeScript/Vite frontend, PostgreSQL via Docker Compose, Flyway migrations.
