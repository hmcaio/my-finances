- [x] `TransferForm.tsx`: redesigned as a Plain/Trade confirmation toggle. Trade mode: cash account + INVESTMENT account pickers, dynamic add/remove line rows (product scoped to the picked INVESTMENT account's holdings via `useInvestmentHoldingsByAccount`, side, quantity, unit price, optional resulting balance, "Close this holding" checkbox shown only for SELL lines), one taxes field, and a read-only computed net-settlement/direction preview.
